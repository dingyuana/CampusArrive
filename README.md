## 项目简介

微迎新（CampusArrive）是一套面向大学迎新场景的数字化报到系统，服务**新生、辅导员、管理员**三类角色，解决新生报到时"找不到地点、不知道流程、咨询无门"的核心痛点。

v1.0 已上线运行一个学年，覆盖报到流程指引、校园导航（集成高德地图）、进度追踪、学校自主流程配置与三端协作。v1.1 在此基础上快速迭代，新增 **AI 智能助手、无障碍访问改造、家长查看端、系统集成中间件、安全与合规保障** 五大模块。

### 解决的核心痛点

| 痛点 | 解决方式 |
| --- | --- |
| 新生咨询量集中、辅导员重复应答 | AI 助手基于校园知识库 RAG 检索，7×24 小时即时作答 |
| 特殊群体新生操作困难 | WCAG 2.2 AA 级无障碍改造，读屏/键盘/对比度全面适配 |
| 家长信息获取渠道缺失 | 家长查看端 H5 提供只读脱敏进度视图 |
| 跨系统数据手工搬运 | 集成中间件通过网关 + 消息队列 + CDC 准实时同步 |
| 合规基线缺失 | 对标 PIPL、等保 2.0、GB/T 45654-2025、OWASP Top 10 |

## 技术栈

| 层级 | 技术选型 |
| --- | --- |
| 前端 | 微信小程序（学生端）、H5（家长端）、Vue/React（管理端） |
| 后端 | Java + Spring Boot 微服务 |
| API 网关 | Spring Cloud Gateway |
| 消息队列 | RabbitMQ |
| 数据同步 | Debezium CDC（MySQL binlog） |
| AI 平台 | MaxKB v1.10 LTS（知识库 + 工作流编排） |
| 大模型 | DeepSeek V4（内网部署，数据不出校） |
| 地图服务 | 高德地图（经 MCP 协议集成） |
| 数据库 | MySQL（业务库）、向量库（知识库） |
| 部署 | Docker 容器化 · 校园内网 |
| 无障碍 | WCAG 2.2 AA 级 |

## 开发排期

v1.1 采用 6 周快速迭代，团队规模 6 人（后端 2、前端 2、测试 1、DevOps 1）。

```
W1  ████████  基础搭建与 PoC（AI 环境、中间件骨架、测试框架）
W2  ████████  核心开发（知识库构建、网关+队列+CDC、无障碍基线）
W3  ████████  核心开发（对话工作流、集成适配层、家长端）
W4  ████████  集成联调（端到端、性能压测、CDC 一致性验证）
W5  ████████  安全合规（OWASP 测试、无障碍全量自测、合规评估）
W6  ████████  验收上线（UAT、灰度发布、监控告警）
```

**Go/No-Go 决策点**：W4 集成评审 → W5 安全合规评审 → W6 上线评审

## 快速开始

### 环境要求

- JDK 17+
- Node.js 18+
- MySQL 8.0+
- Docker 24+
- 微信开发者工具

### 本地开发

```bash
# 克隆仓库
git clone https://github.com/dingyuana/CampusArrive.git
cd CampusArrive

# 后端服务（待开发阶段补充）
cd backend && ./mvnw spring-boot:run

# 前端小程序（待开发阶段补充）
cd frontend && npm install && npm run dev

# MaxKB + DeepSeek 部署（内网）
docker-compose -f deploy/maxkb-deepseek.yml up -d
```

> v1.1 处于开发前期文档阶段，代码实现将在文档基线确认后启动。
